# machi-shosetsu

まちで見つける小説のMVPです。  
Vite + React + TypeScript で構築し、静的データと `localStorage` だけで完結します。

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## Routes

- `/`
- `/spots`
- `/spots/:slug`
- `/works/:slug`
- `/map`
- `/saved`

GitHub Pages では `https://ryo909.github.io/machi-shosetsu/` で公開する想定です。
